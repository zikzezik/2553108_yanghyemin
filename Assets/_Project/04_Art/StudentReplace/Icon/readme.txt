앱 아이콘(런처 아이콘) 넣는 곳
(PC 빌드의 .exe 아이콘, 모바일 빌드의 홈 화면 아이콘으로 쓰입니다)

파일 목록 (이 이름 그대로 유지):
  app_icon.png   앱 아이콘 - 1024x1024px

규칙:
  - PNG, 정사각형 1024x1024
  - ★ 배경을 꽉 채울 것 (다른 리소스와 반대입니다)
    투명 배경은 플랫폼마다 다르게 보여서 아이콘에는 권하지 않습니다
  - 1024 한 장만 있으면 됩니다. Unity가 작은 크기들을 자동으로 만듭니다
    반대로 작은 그림을 키우는 것은 안 됩니다

★ 반드시 "덮어쓰기"로 바꾸세요
  탐색기에서 이 폴더를 열고 같은 이름(app_icon.png)으로 저장해
  기존 파일을 덮어쓰면 그것으로 끝입니다. Unity에서 따로 할 일이 없습니다.

  Unity 안에서 app_icon.png 를 지우고 새 파일을 넣으면 연결이 끊어집니다.
  그러면 Player Settings 에서 7군데를 다시 지정해야 합니다.
  (방법은 주차별수업 W10_1차_빌드 문서의 "앱 아이콘 넣기" 참고)

지금 들어 있는 그림은 임시입니다. 본인 아이콘으로 바꾸세요.
빌드하기 전에 바꿔야 빌드 결과에 반영됩니다.
