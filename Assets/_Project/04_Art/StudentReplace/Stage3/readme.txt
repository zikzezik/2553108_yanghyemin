스테이지3 그림 넣는 곳 (심화 - 스테이지 확장)

★ 이 폴더는 선택 사항입니다.
  수업 진도(스테이지1)와는 무관하며, 더 만들고 싶은 사람을 위한 것입니다.
  스테이지3는 이미 완성된 상태로 들어 있으니, 그림을 바꾸고 싶을 때만
  이 폴더를 건드리면 됩니다.

  StageGround/       바닥      (1920x1080, 지면 표면은 아래에서 200px)
  StageBackground/   배경 5겹  (1920x1080)
  StageWeather/      날씨 파티클
  Monsters/          Monster1(A와 같은 행동) / Monster2(B) / Monster3(C)
  Environment/       클리어 오브젝트
  UI/                시작 배너, 클리어 배너

★ 몬스터 파일명은 스테이지1과 똑같습니다
  monstera_idle_01.png 처럼 씁니다. 행동을 그대로 재사용하기 때문이고,
  폴더가 이미 Stage3/Monsters/Monster1 로 구분되어 있어 헷갈리지 않습니다.

★ 효과음 파일명은 스테이지1과 다릅니다
  06_Audio/SFX/Stage3Monster1 폴더에 attack.wav 처럼 짧게 씁니다.

그림을 바꾼 뒤에는 Stage3_BackgroundTest 씬을 열고
스테이지 확장 도구에서 반영하세요.
  Tools > Class Template > 심화 - 스테이지 확장 > 스테이지 확장 도구
