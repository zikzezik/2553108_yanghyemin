파일명 (정확히 이 이름으로, 소문자로만):
  ground1.png

  (ground8.png 이상도 추가 가능 - 아래 참고)

규격:
  - PNG, 알파 채널 투명
  - 크기: 1920 x 1080px  ★ 화면 전체 크기입니다 (얇은 띠가 아닙니다)
  - 지면의 윗면(캐릭터가 딛는 표면)이 "아래에서 200px" 되는 지점에 오도록 그릴 것
  - 그 200px 선보다 위쪽은 전부 투명 (불투명하면 뒤 배경이 안 보입니다)
  - 좌우 끝이 자연스럽게 연결되도록 제작 (1 -> 2 -> 3 -> 4 로 이어 붙음)

  +---------------------------+ 1080px (화면 맨 위)
  |                           |
  |        전부 투명           |
  |                           |
  +---------------------------+ <- 아래에서 200px = 캐릭터가 서는 높이
  |///  여기에 지면을 그림  ///|
  +---------------------------+ 0px (화면 맨 아래)
              1920px

★ 바닥 그림은 캐릭터보다 "앞"에 그려집니다
  그리기 순서가 배경 -> 캐릭터/몬스터 -> 바닥 이라서,
  200px 선보다 위에 불투명하게 칠한 부분은 캐릭터를 가립니다.
    - 모르고 지면을 두껍게 그리면  -> 캐릭터 다리가 잘려 보입니다
    - 역이용하면 -> 지면 앞쪽에 낮은 풀/돌/난간을 그려두면
      캐릭터가 그 뒤로 지나가면서 자연스러운 깊이감이 생깁니다

바닥 이미지가 울퉁불퉁해도 상관없습니다 - 캐릭터가 실제로 딛는 충돌 판정은
그림과 별개인 평평한 박스로 처리되고, 그 박스의 윗면이 바로 위 200px 선입니다.

바닥을 7개보다 더 늘리고 싶다면:
  ground8.png, ground9.png ... 를 넣고 아트 반영을 실행하면 프리팹까지는
  자동 생성되지만, 씬에 실제로 배치하는 것은 항상 수동입니다
  (Project 창에서 새로 생긴 프리팹을 Scene 뷰로 드래그).

넣고 나면 BackgroundTest 씬을 열고
"Tools > Class Template > Apply Real Stage Art" 를 실행하세요.
안전하게 여러 번 다시 실행해도 됩니다.
