컷신 그림 넣는 곳

  IntroCutscene/   게임 시작 전 이야기 - cutscene01.png 부터
  EndingCutscene/  게임을 깬 뒤 이야기 - ending01.png 부터

둘 다 1920x1080px 이고, 장수는 자유입니다 (3~5장 권장).
파일명 뒤의 번호 순서대로 화면에 나옵니다.

★ 그림 대신 영상(mp4)을 넣어도 됩니다
  같은 번호 자리에 확장자만 .mp4 로 두면 그 장은 영상으로 재생됩니다.
  그림과 영상을 섞어도 됩니다.

★ 장수를 바꿨다면 Unity에서 아래를 실행해야 반영됩니다
  Tools > Class Template > Refresh Intro Cutscene Slides
  Tools > Class Template > Refresh Ending Cutscene Slides
