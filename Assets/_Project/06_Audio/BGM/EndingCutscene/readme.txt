엔딩 컷신 BGM 넣는 곳

음원 파일 하나를 이 폴더에 넣으면 됨 (이름/확장자 무관 - mp3, wav, ogg 다 됨).
파일이 여러 개면 알파벳순 첫 번째만 쓰이고 경고가 뜨니, 하나만 남겨둘 것.

컷신 화면에 들어가자마자 재생 시작, 장을 넘기거나 되돌아가도 끊기지 않고
계속 반복 재생됨 (타이틀로 넘어가면 자연스럽게 멈춤).

넣은 뒤 Unity에서 아래를 실행하면 자동으로 연결됨.
  Tools > Class Template > Add Background Music To Ending Cutscene Scene

★ 인트로용 명령과 헷갈리지 말 것 - "Ending" 이 들어간 쪽입니다.

소리를 어디서 구하는지는 아래 문서 참고.
