스테이지2를 클리어하는 순간 1번만 재생되는 사운드 넣는 곳 (심화)

파일 이름은 반드시 "level_clear_bgm" 으로 시작해야 함 (소문자로만,
확장자는 mp3/wav/ogg 등 무관).

★ 반복되는 배경음악이 아니라 한 번 울리는 소리입니다 (2~5초 정도).
  이 소리가 울리는 동안 스테이지 BGM은 자동으로 멈춥니다.

넣은 뒤 Stage2_BackgroundTest 씬을 열고 스테이지 확장 도구의
"Add Stage Start & Clear To Scene" 을 실행하면 자동으로 연결됨.
  Tools > Class Template > 심화 - 스테이지 확장 > 스테이지 확장 도구
