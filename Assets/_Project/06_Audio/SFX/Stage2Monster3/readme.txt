Stage2 몬스터3 효과음 넣는 곳 (심화 - 스테이지 확장)

파일명 (정확히 이 이름으로, 소문자로만):
  attack1    공격 1
  attack2    공격 2
  hit        맞았을 때
  death      죽었을 때

★ 스테이지1과 파일명 규칙이 다릅니다
  스테이지1은 monsterc_attack1 처럼 접두사가 붙지만, 확장 스테이지는
  폴더 이름(Stage2Monster3)이 이미 구분해주므로 attack1 처럼 짧게 씁니다.

몬스터3은 몬스터C와 같은 행동을 재사용합니다.
확장자는 자유 (wav / mp3 / ogg 다 됨).

넣은 뒤 스테이지 확장 도구에서 "몬스터 프리팹 3개 만들기/다시 반영"을
누르면 자동으로 연결됩니다.
  Tools > Class Template > 심화 - 스테이지 확장 > 스테이지 확장 도구
