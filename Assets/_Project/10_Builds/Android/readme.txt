모바일(Android) 빌드를 저장하는 곳

Unity 상단 File > Build Settings 에서 플랫폼을 Android 로 바꾼 뒤 Build 를
누르고, 저장 위치로 이 폴더를 지정하면 됩니다.

파일 이름은 M_최종빌드_학번이름.apk 형식입니다 (예: M_최종빌드_123456홍길동.apk).

  ** 첫 Android 빌드는 20~60분 걸립니다. IL2CPP 변환 때문입니다. **

  옆에 같이 생기는 ..._BurstDebugInformation_DoNotShip 폴더는 제출하지 마세요.
  이름 그대로 배포용이 아닌 디버그 정보입니다.

제출:
  apk 파일을 각자의 구글 드라이브에 올리고 링크로 제출합니다.

  빌드 결과물은 용량이 커서 GitHub 에는 올라가지 않도록 해두었습니다.
  빌드해도 GitHub Desktop 의 변경 목록에 뜨지 않는 것이 정상입니다.

작업이 끝나면 플랫폼을 Windows 로 되돌려 두세요. 안 그러면 다음 PC 빌드 때
다시 전환하느라 오래 걸립니다.
