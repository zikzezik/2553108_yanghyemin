PC(Windows) 빌드를 저장하는 곳

Unity 상단 File > Build Settings 에서 Build 를 누르고, 저장 위치로 이 폴더를
지정하면 됩니다. 그 안에 원하는 이름의 하위 폴더를 만들어도 됩니다.

빌드하면 이런 것들이 같이 생깁니다:
  2D_Action_Game.exe        실행 파일
  2D_Action_Game_Data\      게임 데이터 폴더
  UnityPlayer.dll           실행에 필요한 파일

  ** exe 파일 하나만 옮기면 실행되지 않습니다. 전부 같은 자리에 있어야 합니다. **

제출:
  이 폴더를 통째로 압축해서 각자의 구글 드라이브에 올리고 링크로 제출합니다.
  압축 파일 이름은 PC_최종빌드_학번이름 형식입니다 (예: PC_최종빌드_123456홍길동).

  빌드 결과물은 용량이 커서 GitHub 에는 올라가지 않도록 해두었습니다.
  빌드해도 GitHub Desktop 의 변경 목록에 뜨지 않는 것이 정상입니다.
